# Haushalt

A small household and lifestyle expense tracker for managing spend across stores and categories such as rent, utilities, insurance, children, and everyday lifestyle costs.

## Run locally

```bash
python app.py
```

Then open http://localhost:8000 in your browser.

## Features

- Track expenses by date, store, category, amount and description
- Support categories for household, utilities, insurance, children, lifestyle, transport, food, and other
- View total spend and category totals in a simple dashboard
- Store data locally in `data/expenses.json`
